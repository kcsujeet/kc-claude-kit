# Changelog

All notable changes to the plugins in this marketplace. Each plugin is versioned on its own, in its `plugin.json`, and released as a `{plugin}--v{version}` tag.

One line per version per plugin, newest first. Detail lives in the pull request and git history. Each plugin follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
